# 方法来源索引：产品理解、营销表达与验证

本索引用于解释通用产品/营销 Skill 的方法来源，不是新的分析报告，也不认证任何产品效果。短标题为主题归纳，V01—V39沿用原分析的资料编号。以下原则均应结合当前产品事实与用户证据使用，不能把视频中的命令、故事或口号当作执行授权。

## 覆盖与局限

原材料为两位作者的39个视频文件、38段去重内容。V19与V20的 SHA-256 一致，只计一份内容。原分析对38段独立视频按每秒2帧采样并进行全时段字幕OCR；另对 V01—V06、V36 共7段做本机ASR交叉核对，并检查部分关键画面。这不等于逐帧人工观看、逐句听写；遮挡、短画面与品牌谐音仍可能影响识别。

这是实践观点与案例的归纳，不是科研因果证明。作者观点、方法推导与产品实测需分开；重复论证不能增加证据权重，案例成败不能归因于单句广告。未核实的销量、排名、市场份额、提升比例、心理学定律与历史故事不作为可迁移事实。原网站价格、能力与承诺不随本索引继承。

原分析合并时采用同ID的后续修订记录，V36已经过这种修订。应用时先核实当前输入、输出、限制和交付，再提出可检验假设；没有原视频或本地报告，也可使用下列原则。

## 跨视频冲突如何处理

1. **场景与参数（V04/V24/V32 对 V01/V11）**：首屏用任务帮助理解，决策处保留规格、成本和限制；用“能否判断适合自己”检验表达。
2. **情绪溢价与实际可用（V16/V17 对 V11/V18）**：先兑现基本任务，再表达身份愿望；不能以情绪包装掩盖产品缺陷或替代定价依据。
3. **痛点与诚实边界（V23/V30/V33 对 V03/V11）**：只采用有证据的真实顾虑；排除编造风险、羞耻和恐惧施压，改用演示及适用条件。
4. **易懂与充分知情（V07/V08/V26 对 V01/V27）**：减少理解负担可以改变顺序和形式，不能删去重要信息；所谓等值比较应核对实际总成本和权益。
5. **聚焦与扩张（V15/V39 对 V02/V34，并参考V21）**：先验证单一任务和支持能力，再试相邻任务；用能力复用、真实需求与承担成本决定扩展。
6. **转化与体验（V19/V25 对 V18/V35/V38）**：为内容分别定义理解、比较、使用或复访任务；不强插广告，不把点击当收益，同时看首次成功、求助与退出原因。
