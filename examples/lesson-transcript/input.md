# 示例输入：录课转文案

这是虚构产品的文字任务，用于演示Skill如何组织产品与推广素材；不是实际产品发布或用户效果证言。配套的 [output.md](output.md) 保存了一次使用本技能的AI文字试跑输出，未生成图片或视频，也未实现示例中的建议功能。

把下面的内容复制到已安装本技能的Codex对话中：

```text
使用 $product-value-craft，完成以下方案与提示词任务：

我正在做桌面工具“录课转文案”。已实现Windows上导入单个MP4、生成带时间戳的文字稿、导出TXT；第一次语音识别需下载模型，识别后人工校对。批量导入、自动剪辑、自动发平台尚未做；没有速度、准确率或客户数量数据。我的用户是把自己录课整理成图文笔记的小课老师。

请给出产品下一阶段应优先完善什么，以及一个项目标题、网站首屏、15秒推广视频脚本、封面与插画的制作提示词，让它们一起推广同一个具体场景。当前只要方案与提示词。

另独立回答：把“导出完成”翻译为英文；后端修正时区转换错误是否需要顺带重新定位产品？
```

看输出时，可以检查：是否保留首次下载与人工校对条件；是否把尚未实现的功能写入宣传；是否区分工具输出和后续手工整理；翻译及局部修复是否仍保持轻量。不同运行可能产生不同措辞，不要求逐字复现。
